SCENARIO 2: SOUMISSION PREUVE
─────────────────────────────────────────────────────────────────────────

  INPUT:                          │ DECISION           │ ACTION
  ─────────────────────────────────────────────────────────────────────
  Account suspended               │ REJECT             │ Show "Account suspended"
  Rate limit (>5/day)             │ REJECT             │ Show "Daily limit reached"
  Rate limit (>50/week)           │ REJECT             │ Show "Weekly limit reached"
  File size < 50KB               │ REJECT             │ Show "File too small"
  File size > 2MB                │ REJECT             │ Show "File too large"
  Format != PNG/JPG              │ REJECT             │ Show "Only PNG/JPG"
  Resolution < 540x720           │ REJECT             │ Show "Min 540x720"
  Duplicate (same file 24h)      │ REJECT             │ Show "Already submitted"
  AI score < 0.3                 │ REJECT + LOG       │ Reject + count violation
                                 │                    │ (increment counter)
  AI score 0.3-0.6               │ APPROVE + FLAG     │ Approve but flag for
                                 │                    │ manual review (admin queue)
  AI score > 0.6                 │ APPROVE            │ Accept and process payment
  ─────────────────────────────────────────────────────────────────────

SCENARIO 3: GESTION VIOLATIONS
─────────────────────────────────────────────────────────────────────────

  REJECTION COUNT │ ACTION               │ EMAIL NOTIFICATION
  ────────────────┼──────────────────────┼─────────────────────────────
  1               │ NONE                 │ "Proof rejected" + guidelines
  2               │ NONE                 │ "Second rejection" + help
  3               │ SUSPEND 24H          │ "⚠️ Account suspended 24h"
  4-6             │ SUSPENDED (24h)      │ "Still suspended"
  7               │ SUSPEND 7D           │ "🔴 Account suspended 7d"
  8-14            │ SUSPENDED (7d)       │ "Still suspended"
  15              │ BAN                  │ "❌ Permanently banned"
  ────────────────┼──────────────────────┼─────────────────────────────
  
  SPECIAL: If AI_SCORE < 0.2 AND REJECTIONS >= 3 → BAN INSTANTLY

SCENARIO 5: ADMIN MANUAL REVIEW
─────────────────────────────────────────────────────────────────────────

  AUTO-FLAGGED ITEMS:
  ─────────────────────────────────────────────────────────────────────
  ✓ AI score 0.3-0.6 (low confidence)
  ✓ User has 3+ rejections
  ✓ Image similarity > 95% (duplicate)
  ✓ User with pattern of bad submissions

  ADMIN ACTIONS:
  ─────────────────────────────────────────────────────────────────────
  APPROVE:
    - Change status to "verified"
    - Release payment to user wallet
    - Send "Payment approved" email

  REJECT:
    - Change status to "rejected"
    - Increment user violation counter
    - Send "Proof rejected" email
    - If counter reaches 3/7/15 → Auto-suspend/ban

SCENARIO 6: FRAUD DETECTION PATTERNS
─────────────────────────────────────────────────────────────────────────

  PATTERN DETECTED           │ AUTO-ACTION
  ─────────────────────────────────────────────────────────────────────
  > 10 submissions/day       │ Suspend, manual review
  Same image 5+ times        │ Reject all, notify admin
  Different accounts same IP │ Flag all accounts for review
  Submission right after     │ Automatic rejection (bot pattern)
  campaign creation          │
  Always low AI scores       │ Suspend after 3, then ban
  Never passing verification │ Pattern analysis, manual review
  ─────────────────────────────────────────────────────────────────────
