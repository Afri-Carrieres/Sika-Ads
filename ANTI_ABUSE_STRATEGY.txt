════════════════════════════════════════════════════════════════

PROBLÈME IDENTIFIÉ:
  - Utilisateurs créent campagnes de test
  - Soumettent preuves non conformes
  - Spamment avec fausses soumissions
  - Abusent du système

════════════════════════════════════════════════════════════════
  SOLUTION: 7 COUCHES DE SÉCURITÉ
════════════════════════════════════════════════════════════════

1️⃣ VALIDATION FRONTEND (UX Prevention)
   ✓ Limite soumissions: 5/jour, 50/semaine
   ✓ Valide taille image: 50KB-2MB
   ✓ Valide résolution: min 540x720
   ✓ Google reCAPTCHA v3 (anti-bot)
   ✓ Validation budget: 10k-500k XOF

2️⃣ VALIDATION BACKEND (Sécurité stricte)
   ✓ Check suspension utilisateur
   ✓ Rate limiting (Redis)
   ✓ Duplicate detection (hash)
   ✓ Vérification compte age (new acc = plus strict)
   ✓ Historical checks (rejections antérieures)

3️⃣ CONTENT VERIFICATION (AI/ML)
   ✓ Google Cloud Vision API
   ✓ Détection texte (view count)
   ✓ Détection screenshot (mobile interface)
   ✓ Watermark detection (Photoshop, Canva)
   ✓ Manipulation detection (forensics)
   ✓ Score: 0-1 (0.3=reject, 0.6=review, 0.6+=approve)

4️⃣ REPUTATION SYSTEM (Blocage progressif)
   ✓ 1er rejet: Email warning
   ✓ 3 rejets: Suspension 24h
   ✓ 7 rejets: Suspension 7 jours
   ✓ 15 rejets: Ban permanent
   ✓ Si score < 0.2 + 3 rejets: Ban instant

5️⃣ VERIFICATION REQUIREMENTS (Progressive)
   New account (< 7j):
     - Email verified (requis)
     - Phone verified (requis)
     - Payment method (requis)
     - Max 1 campaign

   Young account (7-30j):
     - All above
     - Max 5 campaigns

   Established (> 30j):
     - All above
     - Unlimited campaigns

6️⃣ MANUAL REVIEW DASHBOARD (Admin)
   ✓ Queue: Submissions flagged by AI (score < 0.6)
   ✓ Show: Image + AI analysis + user history
   ✓ Admin actions: Approve / Reject with reason
   ✓ Impact: Release payment ou increment violation

7️⃣ MONITORING & ALERTS
   ✓ Auto-flag: AI score < 0.6
   ✓ Auto-flag: 3+ rejections by user
   ✓ Auto-flag: Image similarity > 95%
   ✓ Alert: User with 5+ rejections
   ✓ Dashboard: Admin notifications
